Google Search Console のデータを使って、指定したキーワードの検索順位を日々記録し、ブラウザのグラフで確認するためのツールです。

一度設定しておくと、サイトごと・キーワードごとの順位をローカルファイルに保存できます。実行後にはHTMLレポートをブラウザで開き、順位推移の折れ線グラフ、前回比、`UP` / `DOWN` / `NA` などを確認できます。ExcelやGoogleスプレッドシートで見られるCSVも出力できます。

このリポジトリは、購入前に機能・動作条件・利用条件を確認するための公開資料です。販売するスクリプト本体やインストーラーは含まれていません。本体はBOOTHの販売ページから購入する配布ファイルに含まれます。

## できること


- 複数サイトのキーワード順位をまとめて取得
- 指定したキーワードだけを記録
- 前回の記録と比べて、上がった・下がった・変わらないを表示
- 履歴を `data/rank_history.tsv` と `data/rank_history.csv` に保存
- 日ごとのレポートを `reports/` に保存
- ブラウザで見られる順位推移グラフを自動表示
- HTMLレポート内で順位や `NA` の意味を確認
- ExcelやGoogleスプレッドシートで開きやすいCSVを出力
- 設定ミスを確認する診断コマンドを実行
- 保存せずに結果だけ確認するテスト実行
- macOS/Linuxで毎日自動実行

## レポートの表示例

[サンプルレポート](docs/sales-assets/demo-report.html)は、架空のサイトとキーワードを使った表示見本です。実際の順位データやSEO成果を示すものではありません。

GitHub上ではHTMLのソースが表示されます。表示を確認するには、HTMLファイルをダウンロードし、手元のブラウザで開いてください。サイトの選択、表示期間の切り替え、順位推移グラフ、前回比を確認できます。

たとえば、前回の平均掲載順位が8.50位、今回が6.25位なら、前回比は「8.50 − 6.25 = +2.25」で、順位改善を示します。比較対象は、同じサイト・キーワードで今回より前に記録された最新の数値順位です。前日の数値とは限りません。

## 取得する順位とデータの制約

取得するのは、Google Search Console APIが返す、日本からのGoogleウェブ検索の「平均掲載順位」です。今この瞬間にGoogle検索したときの順位や、特定の記事・端末だけの順位を取得するものではありません。検索結果ページのスクレイピングは行いません。

Search Consoleのデータには反映までの時間差があり、APIの日付はカリフォルニア時間を基準に扱われます。初期設定では4日前のデータを取得しますが、その日付のデータを必ず取得できるとは限りません。

APIはすべての検索語を返すとは限りません。本ツールは初期設定でクリック数の多い先頭25,000行を取得するため、対象キーワードに表示実績があっても、少数のクエリの省略や取得上限により結果に含まれない場合があります。

`NA` は、今回のAPI結果に対象キーワードがない状態です。検索圏外や表示回数ゼロを、それだけで意味するものではありません。対象日全体のデータも確認できない場合は、集計待ちか表示データなしを判別できないため、履歴や日次レポートの保存を保留することがあります。

## 必要な環境と初回設定


- macOS または Linux
- ターミナルでコマンドを実行できる環境
- `curl`
- `jq`
- `openssl`
- Google Cloud のサービスアカウントJSONキー
- Google Search Console の対象プロパティ権限

Google Cloudのサービスアカウントを用意し、Search Console APIを有効にしてJSONキーを発行します。その後、対象のSearch Consoleプロパティにサービスアカウントの権限を追加し、購入したツール側にキーの場所・サイト・キーワードを設定します。詳しい手順は配布ファイル内のREADMEに記載しています。

導入には、ご自身によるターミナル操作とGoogle Cloud・Search Consoleの設定が必要です。JSONキーは認証情報のため、第三者への共有や公開をしないでください。

Windows単体環境での動作は保証していません。毎日の自動実行には、OS側でcron等の設定が必要です。パソコンの電源やスリープ状態によっては、予定時刻に実行されない場合があります。
